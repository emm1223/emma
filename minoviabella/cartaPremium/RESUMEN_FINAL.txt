🚀 CÓMO USARLA (PASO A PASO)
================================================================================

PASO 1: PERSONALIZAR TEXTOS
   Abre → index.html
   Busca → Los textos que quieres cambiar
   Edita → Pon tus propios mensajes
   Ejemplo: <h1 class="hero-title">Para Ti</h1> → <h1>Tu Nombre</h1>

PASO 2: AGREGAR TU CANCIÓN
   Opción A (Local):
      1. Crea carpeta "music" en cartaPremium/
      2. Pon tu archivo: canción.mp3
      3. En consola (F12): addAudio('./music/canción.mp3')
   
   Opción B (Spotify):
      1. Copia el embed de Spotify
      2. Pega en la sección de música en index.html

PASO 3: CAMBIAR COLORES (Opcional)
   Abre → styles.css
   Busca → :root {
   Cambia → --accent-gold: #d4af37; (pon otro color)
   Ejemplo: --accent-gold: #ff69b4; (rosa)

PASO 4: AGREGAR FOTOS
   1. Crea carpeta "fotos" en cartaPremium/
   2. Pon tus mejores fotos de ustedes
   3. La página las mostrará en la galería

PASO 5: PUBLICAR EN INTERNET
   Opción 1 (RECOMENDADA): Netlify
      1. Ve a https://netlify.com
      2. Arrastra la carpeta "cartaPremium"
      3. ¡En 10 segundos tendrás el enlace!
   
   Opción 2: GitHub Pages
      1. Sube a un repositorio
      2. Activa GitHub Pages
      3. Tendrás un URL público
   
   Opción 3: Vercel
      1. Ve a https://vercel.com
      2. Conecta GitHub
      3. Auto-deploy automático

PASO 6: COMPARTIR EN INSTAGRAM
   1. Sube una foto de ustedes dos
   2. Escribe descripción emotiva
   3. En la historia, agrega el link
   4. ¡Que todos vean lo mucho que la amas!

💡 TECNOLOGÍA RESPONSIVA USADA
================================================================================

FUENTES ESCALABLES (clamp)
   font-size: clamp(1rem, 2vw, 2rem);
   → Mínimo: 1rem | Fluido: 2vw | Máximo: 2rem
   → Se ajusta automáticamente

GRID RESPONSIVO
   grid-template-columns: repeat(auto-fit, minmax(250px, 1fr));
   → Se adapta al ancho disponible
   → Crea columnas automáticamente

ESPACIOS FLUIDOS
   padding: clamp(30px, 5vw, 40px);
   → Mínimo: 30px | Fluido: 5% viewport | Máximo: 40px

MEDIA QUERIES MÚLTIPLES
   6 puntos de quiebre específicos
   → Cada tamaño optimizado
   → Transiciones suaves

PANTALLAS TÁCTILES
   Detecta y optimiza para móvil
   → Hover → Active
   → Links con buen tamaño para dedos
