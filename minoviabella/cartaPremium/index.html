✨ Instrucciones de Personalización

1. Agregar Canción

Edita script.js y busca "AQUÍ VA TU CANCIÓN" para poner el enlace de Spotify o un audio local.

2. Personalizar Mensajes

Cambia los textos en este HTML según lo que quieras decirle. Son super fácil de encontrar.

3. Agregar Fotos

Crea una carpeta /fotos y agrega tus imágenes. El JavaScript las cargará automáticamente.

4. Cambiar Colores

En styles.css busca la sección :root para cambiar los colores principales.

5. Cambiar Canción

Para Spotify: usa un embed. Para audio local: sube el archivo .mp3 a la carpeta /music
